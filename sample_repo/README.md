# Calculator Sample Repository

This repository provides a controlled coding task for evaluating autonomous AI agents running inside Celesto sandboxes.

## Purpose
The agent is tasked with:
1. Running pytest to discover failing test cases.
2. Inspecting `calculator.py` to diagnose the error.
3. Editing `calculator.py` to repair the function.
4. Rerunning `pytest` to verify that all tests pass.
